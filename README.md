# DoubleTap.cc

DoubleTap key management system with Firebase authentication.

## 🌐 Live Site

Visit: [doubletap.cc](https://doubletap.cc)

## 📁 Pages

- **Home:** `/` - Redirects to login
- **Login:** `/login` - User authentication  
- **Dashboard:** `/dashboard` - Key management and subscription

## 🔥 Features

- Firebase Authentication (Email/Password & Google Sign-In)
- License Key System
- Subscription Management
- Discord Bot Integration
- Linkvertise Key Generation (3 checkpoints)
- Clean URL structure

## 🚀 Tech Stack

- HTML5, CSS3, JavaScript
- Firebase Authentication
- GitHub Pages Hosting

## 🔐 Security

- Firebase Auth for user management
- Key validation and expiration tracking
- Anti-bypass token system for key generation
